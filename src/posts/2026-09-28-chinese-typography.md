中文排版和西文排版，最核心的差别不在字体，而在“密度”。汉字是等宽的方块，没有词间空格，一行里能塞下的信息比英文多得多。如果直接套用英文网页的默认值，读起来就会觉得闷。

下面是我反复调整过的几个值，以及它们背后的理由。

## 内容宽度比字号更重要

正文宽度我控制在 `36em` 左右。按 18px 的字号算，一行大约 35 个汉字。这个长度接近纸质书的版心，眼睛从行尾回到行首时不容易串行。

```css
.prose {
  max-width: 36em;
  font-size: 1.0625rem;
  line-height: 1.9;
}
```

行高给到 1.9，比英文常用的 1.6 高不少。原因还是密度：汉字没有升部和降部形成的天然空隙，行与行之间需要更多呼吸。1.9 读起来松，但不散。

## 字体栈要诚实

网页上的中文字体，最终由读者的系统决定。与其声明一个下载不下来、动辄几 MB 的字体，不如把常见系统字体排好序：

```css
font-family: "PingFang SC", "Hiragino Sans GB", "Source Han Sans SC",
  "Microsoft YaHei", system-ui, -apple-system, sans-serif;
```

标题可以用衬线体做一点区分，但正文我坚持无衬线。屏幕上的宋体在小字号下容易糊，除非你有能力做字形微调，否则得不偿失。

## 标点与空格

几个容易忽略的小地方：

- 中文正文里夹英文单词时，左右各留一个空格，读起来会顺很多；
- 省略号用 `……`，不要用六个点；
- 破折号用 `——`，占两个汉字宽；
- 引号用直角引号或弯引号都行，但全文要统一；
- 数字和单位之间通常不加空格，比如“3 分钟”；数字与中文之间加一个空格，比如“第 3 章”。

这些规则没有一条会让人拍案叫绝，但它们叠在一起，决定了页面是“能读”还是“好读”。

## 链接与下划线

我一度把链接做成红色，后来改回了下划线加同色文字。红色太抢眼，正文里出现三四个链接，页面就变得像警告框。

下划线更安静，也更符合直觉。为了不让下划线贴着字，我用 `text-underline-offset` 把它往下推一点，再配合 `text-decoration-thickness` 调细：

```css
a {
  text-decoration: underline;
  text-decoration-thickness: 1px;
  text-underline-offset: 0.22em;
  text-decoration-color: color-mix(in srgb, currentColor 35%, transparent);
}
```

悬停时再把下划线加深。变化很小，但读者能感觉到反馈。

## 最后

排版没有“完成”的那一刻。每隔一段时间回头看自己的页面，总会发现新的问题。好在文字是耐看的，改一点，再读一遍，就够了。
