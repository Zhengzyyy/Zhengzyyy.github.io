我是一名开发者，大部分时间和浏览器打交道。喜欢把复杂的东西拆开，找到里面真正起作用的几个零件，然后再装回去。

这个博客是我留给自己的一个角落，用来放那些不适合留在聊天记录里的想法。

## 现在

目前主要做前端开发：设计系统、交互细节、构建流程，以及那些“用户不会注意，但少了就会不舒服”的地方。工作之外，我会读一点书，拍一些不好看的照片，偶尔在纸上画方块。

对工具的态度是够用就好。比起学一个新的框架，我更愿意把已经会的东西用得再熟一点。

## 我关心的事

- **克制**：一个好的界面，往往是因为少做了什么，而不是多做了什么。
- **可读性**：文字是网页最古老、也最重要的界面。
- **可维护性**：代码是写给人看的，顺便让机器执行。
- **诚实**：不假装懂得比自己实际懂得多，也不把没想清楚的东西写得像结论。

## 这个博客

站点是静态的，用 Node 脚本从 Markdown 构建，托管在 GitHub Pages。没有数据库，没有后端，也没有统计脚本。设计上借用了至上主义的几何语言：纸白、近黑、一点红，方块、圆与细线。

所有图形都是自己画的，不是对某幅画的复制。如果你在某个形状里看到了熟悉的影子，那大概是风格本身的回声。

## 写作之外

如果不在电脑前，我可能在：

- 读一本读得很慢的书；
- 沿着河边走路，听播客；
- 整理桌子，然后把它弄乱；
- 试着把一件事用更短的话说清楚。
